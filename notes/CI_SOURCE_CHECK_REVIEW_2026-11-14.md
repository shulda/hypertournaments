# Independent CI source-check review, 2026-11-14

Reviewed `tools/project_sources.py`, `tools/test_project_sources.py`, and
`.github/workflows/lean.yml`. The change fixes the real CI false positive
where the old grep interpreted the English word “admit” in a mathematical
doc comment as a proof tactic. The Lean proof sources remain unchanged.

No blocking issue remains within the source checker's intended role as
an early diagnostic. The existing kernel build and complete defining-module
axiom audits remain the proof-trust boundary.

`lean_code` masks nested block comments, line comments, ordinary strings,
character literals, and hash-delimited raw strings while preserving
newlines and separating adjacent code tokens. `proof_placeholders` uses
that shared mask to locate plain code tokens `sorry`, `admit`, and `axiom`
without matching identifier fragments or mathematical prose. Both the
default receiving-source scan and `--proofs-only` check all own sources,
including the facade and readable audit module. Vendor-byte and import
closure validation remain unchanged.

During review, two concrete gaps in the initial masker were reproduced
with the receiving Lean compiler: a double-quote character literal and
a raw string ending in a literal backslash could make the masker hide a
following real `sorry`. Root corrected both before this final review and
added regressions. The corrected checker detects those following holes,
handles embedded quotes in hash-delimited raw strings, and preserves
line numbers across escaped newlines.

The checker is not a complete Lean parser. In particular, expressions
inside interpolated strings and terms generated by macros are not
established safe by lexical masking. The unchanged full declaration
audit, with allowlist `propext,Classical.choice,Quot.sound`, is what rejects
`sorryAx` or custom axioms in such elaborated declarations. No proof-trust
claim is transferred to this Python preflight.

The workflow now runs the regression suite and default source check, and
replaces the prose-sensitive grep with `--proofs-only`. The exact-head
checkout, `lake --rehash build`, readable declaration audit, and complete
four-prefix audit (`Hypertournaments`, `CCO`, `PartiteConstruction`,
`SuccessorTree`) are retained unchanged.
