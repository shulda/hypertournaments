# Lean files and their mathematical statements

This is the reverse of the paper-to-Lean correspondence: choose a defining
file to see the statements or definitions it supplies in the three texts.
Each source entry links to its arity, hypotheses and complete Lean names.

The index covers the defining files of the catalogued interfaces. Smaller
implementation helpers are reached through their imports and the
[proof architecture](Proof-architecture), rather than being presented as
separate paper theorems.
